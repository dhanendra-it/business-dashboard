# Performance Desk

Business Performance and Revenue Analytics dashboard. React, Vite, Tailwind CSS, Recharts, Lucide icons. All data is generated in the browser, no backend or database.

## Run

    npm install
    npm run dev

## Build

    npm run build

The production files are created in `dist`.

## Deploy

Vercel or Netlify: import the project, build command `npm run build`, output directory `dist`.
